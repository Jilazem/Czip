Run `python3 "${CLAUDE_PLUGIN_ROOT}/czip_cli.py" map` with the user's arguments: $ARGUMENTS
Pass arguments as data; do not evaluate them as shell code. `czip` without arguments is pack; other subcommands are listed by help.

Show the bounded map of the explicitly selected package; do not export the full history.

Use the system/user language. Both languages name the same operation: `harita` / `map`. `--lang tr|en` is an explicit override.
