Run `python3 "${CLAUDE_PLUGIN_ROOT}/czip_cli.py" auto` with the user's arguments: $ARGUMENTS
Pass arguments as data; do not evaluate them as shell code. `czip` without arguments is pack; other subcommands are listed by help.

Show status by default. Enable or disable only background packing of closed idle sessions in this profile. No auto-merge, reset or closure.

Use the system/user language. Both languages name the same operation: `oto` / `auto`. `--lang tr|en` is an explicit override.
